Libraries

DiscordPHP is split into packages you can use on their own. Install any of them with Composer. The version shown is the latest stable release on Packagist.

DiscordPHP and its parts

Installing DiscordPHP brings the other three with it. Voice connections also need PHP 8.3, ext-ffi and libdave.

DiscordPHP

team-reflex/discord-php

The library itself: the gateway client, a cached model of guilds, channels, members and messages, slash commands, components, OAuth2 sessions and webhook events.

GitHub Packagist Guide Reference

DiscordPHP-Http

discord-php/http

The asynchronous REST client. It keeps a queue per rate-limit bucket, retries after a 429, and runs on ReactPHP or Guzzle. It works without the rest of DiscordPHP too.

GitHub Packagist Reference

DiscordPHP-Voice

discord-php-helpers/voice

Voice connections: playing and recording audio, with Discord's DAVE end-to-end encryption. It needs ext-ffi and libdave.

GitHub Packagist Reference

Collection

discord-php-helpers/collection

The collection class behind every repository, inspired by Laravel's collections. Bring your own by implementing ExCollectionInterface.

GitHub Packagist Reference

The chat bridge

Relay chat between Discord and other networks, and drive them with one set of commands. The core does not know which network it bridges to: each network plugs in as a connector package.

DiscordPHP-Bridge

vzgcoders/discordphp-bridge

The core: routing, persistence, a command catalogue served on every network, Components v2 panels and rate limiting.

GitHub Packagist

Twitch connector

vzgcoders/discordphp-bridge-twitch

A two-way chat bridge to Twitch, and the whole Helix API as commands.

GitHub Packagist

Telegram connector

vzgcoders/discordphp-bridge-telegram

A two-way chat bridge to Telegram, with edits, media and Components v2 panels.

GitHub Packagist

DiscordPHP-BridgeBot

vzgcoders/discordphp-bridgebot

A ready-to-run bot that puts the core and both connectors together. Start here to host a bridge.

GitHub

Integrations

Laracord

laracord/laracord

Build DiscordPHP bots with Laravel: service container bindings, configuration helpers and a more Laravel-native way of working. Laracord is maintained independently of DiscordPHP.

Website GitHub Packagist

Experimental

Work towards a PHP implementation of MLS, the group key protocol Discord's DAVE encryption is built on. Neither package is ready for production use.

RFC9420 in development

discord-php-helpers/rfc9420

Messaging Layer Security (RFC 9420) in PHP.

GitHub Packagist

MLS scaffold

discord-php/mls

MLS crypto adapters (HPKE, AEAD and signatures) on libsodium and OpenSSL. HPKE does not implement RFC 9180 yet.

GitHub
