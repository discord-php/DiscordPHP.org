Releases and compatibility

One view of the ecosystem's tagged releases and runtime requirements. Release versions come from Packagist or GitHub; PHP, DiscordPHP and extension constraints are read from the Composer file at that release. “No Composer metadata” means no readable composer.json was found at the release tag, “Not declared” means the file has no such constraint, and “None declared” means no extensions are required.
